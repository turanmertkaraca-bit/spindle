A redirect loop usually means the middleware runs before the session cookie is written. Read the auth middleware and the login route, then check the order of cookie-set vs redirect.
Found it. The session cookie is set after res.redirect(), so the browser leaves before Set-Cookie is written — the next request looks unauthenticated and loops back. Writing the cookie first fixes it.
✓READsrc/auth/middleware.ts
export function requireAuth(req, res, next) { if (!req.cookies.sid) return res.redirect('/login'); next(); }
